Features

FAQ

Questions we get asked

Is the price data live?

Yes. When you search, the backend queries StockX and GOAT in real time — we don't serve stale cached prices. If a source is unreachable, we show whatever the remaining platform returned and flag it.

What happens if I type something invalid?

You'll see a clear "No results found" message. Invalid or missing input never crashes the app — that's one of our core QA test scenarios.

What if one marketplace is down?

Each scraper fails independently. If StockX times out, GOAT results still render — graceful fallback is built into the aggregation layer.

Do I need an account?

No. Price comparison is open to everyone. Creating an account just lets you save searches and get alerts when a price drops.
